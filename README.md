# Kekenapepe

Build a browser-based 3D endless driving game set in Uyo, Akwa Ibom, Nigeria.

Style: Low-poly 3D, third-person behind-the-vehicle camera (similar to Swoop Chop Chop).

Player vehicle: Start with a keke (tricycle). Later add unlockable mini-bus.

Setting: Stylized Uyo streets. Use real street names: Aka Road, Ikot Ekpene Road, Abak Road, Oron Road, Wellington Bassey Way, Nwaniba Road, Ibom Plaza area.

Gameplay:
- Drive forward automatically with speed control (Brake / Faster buttons + keyboard)
- Switch between 3 lanes
- Dodge other kekes, mini-buses, and cars
- Collect coins
- Pick up passengers at marked spots and drop them for extra points
- Simple missions (e.g. “Reach Ibom Plaza”, “Survive 60 seconds on Ikot Ekpene Road”)
- Crash = game over with funny Uyo/Nigerian message

Mobile-friendly with on-screen controls. Clean modern UI showing score, speed (km/h), current street name, and coins.

Tech stack: Three.js + Vite + vanilla JavaScript (or React Three Fiber if better). Deployable on Vercel.

Make the code clean, modular, and well-commented so it can be extended.
