# Local road music

Add audio files to this folder, then list each file in `playlist.json`:

```json
{
  "tracks": [
    {
      "title": "Track title",
      "artist": "Artist name",
      "src": "track-file.mp3"
    }
  ]
}
```

The in-game player also has an **Add files** control for playing audio from your device for the current session.
